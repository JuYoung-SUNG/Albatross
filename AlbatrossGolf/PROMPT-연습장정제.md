# 골프 연습장 데이터 정제 프롬프트

파이프라인: **[1] 원천 수집 → [2] LLM 정제(이 프롬프트) → [3] 검증 → [4] 포스팅(`--import-golf`)**

## 사용법

1. 연습장 홈페이지·블로그 후기 텍스트를 복사한다.
2. 아래 프롬프트를 LLM 채팅창에 붙여넣고, `[원문 붙여넣기]` 자리에 복사한 텍스트를 넣는다.
3. 결과 JSON을 `.json` 파일로 저장한다.
4. 아래 명령으로 사이트에 반영한다.

```
dotnet run --project Albatross.Collector --configuration Release -- --import-golf "C:\경로\ranges.json"
```

Slug 기준 upsert라서, 같은 연습장을 다시 넣으면 **덮어써서 갱신**된다.

## 프롬프트 (아래 전체를 복사해서 사용)

```
너는 골프 연습장 정보를 정리하는 데이터 정제 전문가다.
아래 [원문]에서 "사실 정보"만 뽑아 JSON으로 만들어라.

[매우 중요한 규칙]
- 원문 문장을 그대로 복사하지 마라. 사실(요금, 좌타석 수, 드라이버 가능 여부 등)만 추출해 짧은 구문으로 재작성한다.
- 원문에 없는 내용은 절대 지어내지 마라. 확인되지 않은 항목은 "미확인"으로 쓰거나 필드를 비워라.
- 광고성 표현("최고의", "강력 추천")은 쓰지 말고 중립적으로 서술한다.
- 요금·시간처럼 변할 수 있는 값은 원문에 적힌 그대로의 수치를 유지한다.

[출력 형식] 아래 JSON만 출력. 설명·마크다운 백틱 금지.
{
  "ranges": [
    {
      "name": "연습장 정식 명칭",
      "type": "파3 | 야외인도어 | 실내 | 스크린 중 하나",
      "region": "수도권 | 강원 | 충청 | 영남 | 호남 | 제주 중 하나",
      "city": "시·군·구 (예: 경기 성남시)",
      "address": "도로명 주소",
      "phone": "전화번호",
      "hours": "영업시간",
      "price": "일일 타석 요금 (평일/주말 구분해서)",
      "leftHanded": "좌타석 여부와 개수 (예: 2개 보유 / 없음 / 미확인)",
      "driverAllowed": "드라이버 사용 가능 여부 (예: 가능 / 불가 / 일부 타석만)",
      "parking": "주차 정보 (예: 2시간 무료)",
      "summary": "이 연습장이 어떤 곳인지 한 문장",
      "highlights": ["장점이나 특징 2~4개"],
      "cautions": ["방문 전 알아둘 점 1~3개"],
      "sourceUrls": ["참고한 URL"],
      "updatedAt": "정보 기준 날짜 (YYYY-MM-DD)"
    }
  ]
}

[원문]
[여기에 홈페이지/블로그 텍스트를 붙여넣으세요]
```

## 검증 체크리스트 ([3] 단계)

포스팅 전에 아래를 확인하면 사이트 신뢰도와 애드센스 심사에 유리하다.

- [ ] 요금·영업시간이 원문과 일치하는가 (LLM이 숫자를 바꾸지 않았는지)
- [ ] 원문 문장을 그대로 옮긴 곳은 없는가 (저작권)
- [ ] 확인 안 된 항목이 "미확인"으로 되어 있는가 (지어내지 않았는지)
- [ ] `sourceUrls`에 출처가 들어 있는가
- [ ] `region`, `type` 값이 정해진 목록 중 하나인가 (필터가 이 값으로 동작)

## 참고

- 사이트는 각 연습장 페이지 하단에 "정보 기준 날짜"와 "방문 전 확인" 안내를 자동으로 표시한다.
- 요금은 자주 바뀌므로 `updatedAt`을 반드시 채우는 것이 좋다.
